# Codex repository instructions

This repository contains **three iPad-friendly educational games** for a seven-year-old child.

**Start by reading `CODEX_HANDOFF.md` in full.** It contains the parent’s goals, current behavior, historical requirements, deployment instructions and next tasks.

## Guardrails
- Preserve working URLs: `/`, `/reading/`, `/stories/` under the GitHub Pages project site `https://spicyguoba.github.io/mathquest/`.
- Preserve existing localStorage data and provide migrations if changing storage format.
- Comprehension game: **4/5 correct is a story pass; only three *different*, consecutive passed stories unlock the next rank; a failed story resets the streak**. Maintain this requirement.
- Focus on kid-friendly, accessible iPad touch interactions, readable text, original content, positive feedback, and useful literacy learning. No ads/tracking.
- Verify behavior and deployment rather than assuming a commit means a working site.
- Parent reports literacy risk on screening measures; never present these games as diagnostic or substitutes for school instruction.
